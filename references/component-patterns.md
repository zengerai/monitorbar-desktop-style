# 组件与业务适配

目标是让用户从菜单栏 / 托盘快速查看状态并完成常用操作。样板中的显示器、四个分页和七天统计属于示例业务，不是通用模板的必选项。

## 从业务到面板

先识别当前对象、最常用动作、选择范围和真实状态，再组合组件。保留现有业务权限、数据流和宿主技术栈；本 Skill 决定呈现方式，不新增后台能力。

基础骨架：身份与上下文 → 必要时的分类导航 → 可滚动内容 → 必要时的状态或提示。面板宽以 360 逻辑单位为起点，高度随内容；原生定位和关闭行为见 [平台契约](platform-contract.md)。

| 模式 | 适用情况 | 呈现与交互 |
|---|---|---|
| 身份标题 | 当前设备、账户或工具上下文 | 图标、名称、一行摘要；更多容纳低频应用动作。右侧快捷动作仅在业务需要时出现，不默认添加电源按钮 |
| 分段导航 | 有多个独立且反复访问的任务组 | 浅灰底、白色选中块、蓝色图标；陌生图标配短标签。单一任务省略导航，不凑四页 |
| 控制组 | 一组连续数值或关联开关 | 白卡片内标题、当前值、直接控制；数值用等宽数字，调整不挤动布局 |
| 短选项 | 少量互斥选择或真实预设 | 浅灰选项，选中浅蓝底与明确状态。列数随标签长度调整，不固定四列；执行动作与选择状态分别表达 |
| 紧凑列表 | 设备、线路、记录或较多模式 | 主信息左、必要说明右；单选留勾选位，记录列表按实际动作设计。列表可作为主要内容，无需逐行再套卡片 |
| 状态提示 | 连接、检测、同步、错误等影响下一步的事实 | 点 / 图标配文字；没有此类信息时省略。局部失败放在相关组，恢复操作靠近问题 |
| 小图表 / 设备预览 | 趋势或设备形态帮助作出决定 | 有真实数据与明确口径才使用；浅色设备预览保持银灰。没有判断价值时省略 |

## 状态契约

- 区分控件当前值、用户请求值与操作结果；异步成功后才确认完成，快速连续操作避免旧结果覆盖新意图。
- 能力确实不支持时隐藏相关组；检测中、临时失效和空列表分别提供准确状态，不把它们当作永久不支持。
- 保留 `hover / pressed / selected / focus / disabled / pending / error` 中实际需要的状态；菜单关闭返回触发器，分页和控件保留键盘语义。主题或分页切换不重置业务值。
- 空状态说明如何得到第一项；权限或依赖缺失提供现有产品允许的恢复动作。危险或不可逆操作沿用业务确认规则，更多菜单不是绕过确认的方式。

## 迁移例子

| 工具 | 内容组合 | 不应照搬 |
|---|---|---|
| 音频 | 当前输出设备、音量 / 静音、输入设备列表 | 显示器插画、分辨率页 |
| 网络 | 当前连接、线路选择、连接 / 断开、必要时的流量趋势 | 硬件亮度与四个固定分类 |
| 剪贴板 | 可选搜索、最近记录列表、固定 / 复制动作、空状态 | 每条记录套卡、虚构连接状态、装饰统计 |

采用 [银白主题](theme-light.md) 的语义颜色与字体层级。需要原作组件尺寸时查 [源码拆解](design-spec.md)，但其中原版配色与显示器专用结构不覆盖以上适配规则。
