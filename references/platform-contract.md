# 平台与交互契约

观察依据为 `app.go` / `panel.go`。标为「建议」的项用于新产品适配，不代表已由原作实现或在本机原生验证。

窗口几何与行为独立于主题。下列白色透明边、橙色品牌块等是原作深色表现；默认浅色实现使用 [银白主题](theme-light.md) 的面板边、银灰标识和蓝色状态，仍保留各平台的原生窗口约束。

## 共用行为

原作点击入口切换面板；右键先关闭浮层再弹原生菜单；重复启动会显示已有面板。窗口可聚焦、有系统阴影，关闭时保存偏好。根据内容重新测量高度，提示出现时可自动增高。

窗口宽 360；内容上限为 `max(area.Height - 230, 200)`。230 是装饰与边距的保守预算，不是固定头部精确高度。初始 600 不是最终高度。滚动区不包含标题、分页、更新条、状态。

**建议补齐并原生验证**：Escape / 点击外部关闭、关闭后的焦点返回、内部原生菜单打开不误关闭。不能仅凭 `NewFlyout` 名称声称这些行为全部已实现。

## macOS

- 根透明，主体不透明；主体圆角 16、白 12% 的 0.7 边。透明区供外角与箭头露出桌面，不是磨砂背景。
- 顶箭头高 10，指向菜单栏图标中心；屏幕边缘重新计算位置，尖端 x 限于 18–342。
- 使用 `IconIsTemplate: true`。菜单栏图标遵循宿主模板能力；橙色品牌块属于面板内部。
- 系统字体、菜单、窗口层级和焦点由原生宿主处理，Web 只能模拟视觉。

## Windows

- 根填实色 `panelBottom`，源码说明用于 ClearType 的不透明背景，不强制窗口整体透明。
- 没有 macOS 顶箭头。Windows 11 圆角与外轮廓交给系统，不再叠自绘外壳。
- 依据图标位置与工作区定位；图标位置不可得时退到主屏工作区右下角，距右 / 底各 12，高度最多工作区减 24。
- 回退时同时设置尺寸与位置，避免先出现在屏幕中间再跳动。
- 本次没有 Windows 10 图，不承诺其窗口也拥有 Windows 11 圆角。

## 数据状态

| 状态 | 规则 |
|---|---|
| 已连接、有能力 | 展示可用控制与当前值 |
| 永久无此能力 | 原作隐藏相应组，仍可用操作继续显示 |
| 正在检测 | 黄色点 / spinner 与文字，不能假报连接 |
| 临时断连 / 失败（建议） | 不等于不支持；保留上下文、反馈错误、重试，必要时禁用依赖通道的操作 |
| 请求进行中（建议） | 只锁冲突动作；滑动按接口合并 / 节流；旧返回不能覆盖新用户意图 |
| 选中 | 用勾选、文本或可访问状态补充颜色 |
| 有更新 | 原作插入窄提示条；安装时显示真实百分比 |

原作自动场景只在时段交替时应用；中途手动改动保留到下一次交替，不立即改回自动值。状态在主线程读写，异步结果回到主线程更新；其他技术栈保持对应的可观察行为。

## 可读性、缩放和动画

360 为逻辑宽度基线，尊重工作区与文本缩放；短屏滚动，字号增加时允许增高 / 拓宽。长名称有可访问全称。实际产品需检查 macOS Retina / 外屏、Windows 100% / 150% / 200%、多屏边缘。

源码未指定自定义弹出 / 分页动画。样板约 120 ms 的颜色过渡是 Web 适配。避免弹簧缩放、大位移和循环发光；减少动态效果时取消过渡。

## 验证界限

Web 样板可验证布局、Token、浏览器内点击、分页、控件、键盘语义。它不能验证真正托盘注册、外部点击、系统焦点、多屏 / DPI、ClearType、设备 API 或功耗。完成实际产品时补齐各原生平台的测试并注明方式。
