# MonitorBar UI 拆解

提取日期：2026-10-15。基线：[`950ec67`](https://github.com/Binaryify/MonitorBar/tree/950ec67b540438578b56e0341503ba1e80f090e2)。尺寸为逻辑单位；映射为 CSS px 仅用于 Web 样板，不是物理像素。

本文保留上游深色源码与几何的提取记录。用户已认可的默认交付为 [苹果风银白浅色](theme-light.md)；新业务的组件组合见 [组件与业务适配](component-patterns.md)。本文原版配色和四页结构不覆盖这些选择。

## 风格与结构

可称为「深色紧凑控制浮层」。精致来自窄幅排版、克制的表面明度、清晰的选中态与直接操作。三层结构是近黑面板 → 低透明度白色卡片 → 稍亮的可点击控件。橙色说明当前页、当前选择、正在调整的量。设备光晕随亮度变化，承担状态表达。

这里的状态栏风格指菜单栏 / 托盘入口及其浮层，不是替换整个系统栏。

```text
菜单栏 / 托盘入口
└─ 弹出面板：宽 360，高度随内容
   ├─ 设备身份：图标 / 名称 / 摘要 / 更多 / 电源
   ├─ 图标分页：概览 / 画面 / 分辨率 / 屏幕时间
   ├─ 当前页：唯一滚动区
   │  ├─ 概览：设备状态 → 输入源 → 亮度 → 音量 → 场景
   │  ├─ 画面：场景 → 自动切换 → 调光 → 色温 → 硬件控制 → 恢复
   │  ├─ 分辨率：刷新率 → HiDPI 列表 → 标准列表
   │  └─ 屏幕时间：当日值 → 7 天图 → 统计口径
   ├─ 有更新时出现的提示条
   └─ 连接状态：小点 + 文字，无适用信息时留空
```

四个分页属于原产品，不是新工具固定模板。标题、分页、状态保持稳定；常用控制尽量直接操作。

## 可复用组件

**IdentityHeader**：产品图标、名称、一行关键上下文；右侧固定更多与快捷动作。长名称省略但提供可访问全称，不能挤掉操作。

**IconTabs**：整条较亮底，一次选一格。原作有 Tooltip 与 Label；Web 适配还需 tab / tabpanel 关联、方向键与焦点。陌生图标可加短文字。

**ControlCard**：图标 + 标题 / 副标题 + 右侧数值，下方滑动 / 步进。变化不造成布局跳动；真实设备确认后才能宣称成功。等宽数字稳定数值位置。

**ChoiceChip / SceneTile**：选中同时改变底、边、文字。4 列来自短名称；长线路名可改两列。场景是业务快捷组合，不是装饰性标签。

**CompactChoiceList**：主值左、解释右、末尾固定勾选位；未选中也保留勾的位置。HiDPI 与标准分组，避免混淆逻辑分辨率与渲染大小。

**StatusFooter**：小点与短文字扫描连接状态，不堆技术日志。连接通道在本产品中有判断价值，其他工具只呈现用户需要的事实。

**MiniUsageChart**：110 高轨道、4 圆角；亮屏橙 30%、操作实橙。两者同柱重叠比较，不相加堆叠。峰值至少按 1 小时归一，统计口径可读。

**DevicePreview（可选）**：屏框 268×151、圆角 8、padding 4；内屏圆角 5；支架 30×18、底座 108×5。`glow = brightness / 100`，屏内橙 alpha = `0.05 + 0.3 * glow`，光晕 alpha = `0.1 + 0.26 * glow`。仅在有设备状态表达价值时保留。

## 迁移规则

稳定复用：窄幅骨架、卡片层次、单强调色、字体层级、图标、直接操作和状态提示。

业务替换：设备画面、分页数量、场景与控制名称、统计数据、更多菜单动作。

平台适配：箭头、窗口圆角 / 阴影、菜单、焦点、图标呈现、多屏定位、DPI 与字体，见 [平台契约](platform-contract.md)。

Web 样板新增的 6 高 range 轨道、20×16 拇指、焦点圈、短过渡、错误 / 禁用样式属于适配。原作 slider / switch 底层由 mygo 绘制，本次未提取依赖内部实现，不能冒充精确源值。

避免大面积磨砂和橙色、带侧栏的网页布局、装饰图表、多层卡片、四分页硬套、盲目复制小字号与小点击区。支持键盘和缩放，让选中不只靠颜色。

## 样板边界

新增 [苹果风银白浅色主题](theme-light.md)：沿用原作结构，重新定义浅色表面、文字与强调色。它是本地设计扩展，非上游精确提取。预览提供深浅选择器，切换不会重置控制状态。

`assets/preview.html` 使用固定示例数据，支持四页、平台切换、输入源、场景、滑动 / 步进、刷新率 / 分辨率、自动切换、能力状态和重试演示。所有变化仅在浏览器内，不连接局域网或控制显示器。

预览保持主要比例与层级；浏览器字体、range、阴影不是原生截图。右侧仓库截图单独标识。真实原生验收仍须在 macOS / Windows 分别执行。
