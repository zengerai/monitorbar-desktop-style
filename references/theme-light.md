# 苹果风浅色 · 银白与蓝

用户于 2026-10-15 明确要求去掉绿色、采用苹果风，并认可本方案作为 Skill 交付。新工具没有既有主题或另行指定时，默认使用此主题：中性银白、石墨文字、浅灰控件和克制的蓝色。保留 MonitorBar 的 360 宽和紧凑控制结构。这是本地 Apple-inspired Web 适配，不是 Apple 官方组件或 MonitorBar 上游主题；不使用或分发专有字体与 SF Symbols。

蓝色主要承担激活和操作反馈。标题、图标底板、设备外框与面板都保持中性。连接点采用蓝色并配“已连接”文字，本浅色方案不再使用绿色。

图形蓝与文字蓝分开：`#007AFF` 用于滑轨、图表等图形；较深 `#0066CC` 用于小号选中文字，其在白底对比约 5.57:1，在选中底约 4.89:1。辅助文字在白底约 5.97:1，在面板底约 5.21:1。以上是指定色对的计算值，不是整套产品的无障碍认证。

## 组件表达

- 分页采用浅灰分段底、白色选中块和短而柔的阴影，选中图标为蓝色。
- 标题区的设备标识用银灰底与石墨线图标，不增加大色块。
- 白色卡片保持弱边界，内层控件采用浅灰，依靠明度与间距区分层级。
- 设备预览使用银灰框、浅灰白屏幕与中性底座，移除有色光晕。亮度依然在数值与滑杆上直接反馈。
- 滑杆为蓝色有效轨道、灰色底轨和白色拇指；图表使用浅蓝 / 蓝色表达两种量。
- 菜单、滚动条、错误状态、焦点和 `color-scheme` 一并适配，不留下原绿色主题色值。
- 辅助说明、图表与场景标签保持 11，主标题与数值层级沿用既有布局。原版深色仍保留原作字号。
- 原生 checkbox 承载 30×18 的浅色开关；可聚焦、可键盘操作。保留现有短颜色反馈与减少动态效果规则，不添加装饰动画。

## 使用与边界

新 Web 实现显式使用 `class="mb" data-theme="light"`。`data-theme="dark"` 或不指定主题保留原始深色 CSS 基线，仅为兼容原版；不能据此把新工具默认做成深色。所有页面共用语义变量，原生项目按角色映射到现有主题系统。

预览 `assets/preview.html?theme=light` 默认显示苹果风银白；`?theme=dark` 为原版深色。切换保留分页、输入源、亮度和场景。右侧是明确标记的上游深色截图，不是本地浅色的原生运行证据。
